How to set up Firebase?

Firebase Setup Guide

1️⃣ Create Firebase Project

Go to Firebase Console, click "Add Project", enter name, click Create

2️⃣ Create Web App

In Firebase project, click "Add App" → Web. Copy your config, especially Project ID and API Key

3️⃣ Enable Firestore Database

Go to Build → Firestore Database → Create Database → Select location → Start in Test Mode

4️⃣ Enable Anonymous Auth

Go to Build → Authentication → Get Started → Enable Anonymous

5️⃣ Paste Credentials

Come back here and paste your Project ID and API Key above
